DEPLOY
======
1. Extract this ZIP into a fresh folder.
2. Upload all 3 files together to your GitHub Pages repo (same folder):
   - DemoInABox.html
   - Learner.html
   - rakbank-logo.jpg
3. Hard refresh: Ctrl+Shift+R (Windows) / Cmd+Shift+R (Mac).

HOW TO USE THE EXPORT
=====================
1. Go to Assign to Learners, pick your course.
2. Add / upload your 40 learners (CSV or manual).
3. Click "Assign to All Learners"  -> all 40 links are created.
4. Click "Export All Links to Excel" -> one .xlsx downloads with all rows.
