============
1) Logo replaced with the new bilingual RAKBANK logo (English + Arabic) - upscaled to 800px wide.
2) All fonts unified to Cabin. Playfair Display serif removed everywhere.
3) All v9 features preserved:
   - Executive learner portal styling (rainbow accent, premium red buttons)
   - Confetti burst from the top when the learner passes and when they complete
   - Bright admin Generate Course view with coloured section rails
   - Add More Content panel with big vibrant buttons
   - Image upload under every content section (Key Concepts, Short Content, Banking Scenario, Flip Cards, Knowledge Check, Key Takeaways)
   - Images travel through the learner link payload

WHAT DID NOT CHANGE
===================
- AI course generation
- Editing / dynamic content addition
- Excel tracking
- Microsoft Forms / Power Automate integration
- Tamper-resistant scoring
- Word audit export

DEPLOY
======
1. Extract this ZIP into a fresh folder.
2. Upload all 3 files to your GitHub Pages repo (same folder):
   - DemoInABox.html
   - Learner.html
   - rakbank-logo.jpg
3. Hard refresh: Ctrl+Shift+R (Win) / Cmd+Shift+R (Mac).
